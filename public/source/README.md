# PANDUAN DROP RESOURCE PROIECTUM STUDIO

Folder ini disiapkan khusus agar Anda dapat dengan mudah memasukkan (*drop*) file gambar/video buatan Anda sendiri untuk menggantikan aset template lama.

---

## Struktur Folder & Penempatan File:

### 1. `/branding`
Letakkan aset identitas brand inti:
- **favicon.png** (Icon monomark "P" ukuran 32x32px atau 512x512px)
- **og-banner.png** (Gambar preview share untuk WhatsApp/Twitter/LinkedIn ukuran 1200x630px)
- **logo.svg / logo.png** (File logo resmi bila ada versi khusus)

### 2. `/works`
Letakkan gambar-gambar studi kasus / portofolio proyek Anda:
- Bisa dibuat sub-folder per proyek jika ada banyak gambar (misal: `/works/proyek-a/`, `/works/proyek-b/`), atau
- Diberi nama yang jelas (misal: `project1-hero.jpg`, `project1-mockup1.png`, dst.)
- Format yang disarankan: JPG, PNG, atau WebP resolusi tinggi (1920x1080 atau 1200x800)

### 3. `/shots`
Letakkan gambar render 3D, animasi pendek, atau visual grafis lepas untuk galeri `/shots`:
- Format: JPG, PNG, WebP, atau MP4 loop

### 4. `/about`
Letakkan foto studio, foto tim / founder (jika ada), atau visual sertifikasi/penghargaan.

---

> **Setelah Anda drop file ke folder ini:**
> Cukup kabari saya filenya sudah di-drop (misal: *"udah gw drop gambar di folder works/proyek-1"*), dan saya akan langsung memetakan, mengoptimalkan, serta memasangnya ke halaman website terkait!
